# ArmClient / GripperClient 使用文档

## 1. 目标
本文档说明如何在电脑端直接使用两个封装类接入机器人消息：

1. `ArmClient`（对应《RoSci RDK 开发说明文档》3.3.2 手臂接口）
2. `GripperClient`（对应《RoSci RDK 开发说明文档》3.3.5 末端夹爪接口）

代码文件：`scripts/arm_gripper_api.py`

## 3. 演示例子二：（读取状态并发送示例指令）
先确保环境变量已配置（同第 2.1 节），然后运行：

```bash
/usr/bin/python3 examples/example2.py
```

该演示会：
1. 读取 `ArmClient` 与 `GripperClient` 状态
2. 打印状态（如 `left_pos`、`gripper_pos`）
3. 发送示例控制指令（`SetWorkMode/SetLeftJointPosition/SetPosition`）

核心代码如下（来自 `examples/example2.py`）：

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from arm_gripper_api import ArmClient, GripperClient
from rosci_robot_message.msg import ArmCommand, GripperCommand


class MyApp(Node):
    def __init__(self):
        super().__init__("my_app")

        self.arm = ArmClient(
            self,
            command_topic="/rosci_arm_command",
            state_topic="/rosci_arm_state",
        )
        self.gripper = GripperClient(
            self,
            command_topic="/rosci_left_gripper_command",
            state_topic="/rosci_left_gripper_state",
        )

        self.create_timer(1.0, self.tick)

    def tick(self):
        try:
            # 读取状态
            left_pos = self.arm.GetLeftJointPosition()
            g_pos = self.gripper.GetPosition()
            self.get_logger().info(f"left_pos={left_pos}, gripper_pos={g_pos}")

            # 发控制命令（示例）
            self.arm.SetWorkMode(ArmCommand.WORK_MODE_JOINT_POSITION)
            self.arm.SetLeftJointPosition([0.0, 0.1, 0.2, 0.1, 0.0, 0.0, 0.0], 0.2, 0.2)

            self.gripper.SetRequestState(GripperCommand.REQUEST_STATE_OPERATION)
            self.gripper.SetPosition([0.2], [0.5])
        except RuntimeError:
            # 还没收到第一帧状态时会触发
            pass


def main():
    rclpy.init()
    node = MyApp()
    try:
        rclpy.spin(node)
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == "__main__":
    main()
```

## 4. RDK 3.3.2 -> ArmClient 函数映射

### 4.1 状态接口
1. `GetJointNum` -> `ArmClient.GetJointNum()`
2. `GetLeftJointPosition` -> `ArmClient.GetLeftJointPosition()`
3. `GetRightJointPosition` -> `ArmClient.GetRightJointPosition()`
4. `GetLeftJointVelocity` -> `ArmClient.GetLeftJointVelocity()`
5. `GetRightJointVelocity` -> `ArmClient.GetRightJointVelocity()`
6. `GetLeftJointTorque` -> `ArmClient.GetLeftJointTorque()`
7. `GetRightJointTorque` -> `ArmClient.GetRightJointTorque()`
8. `GetLeftToolForce` -> `ArmClient.GetLeftToolForce()`
9. `GetRightToolForce` -> `ArmClient.GetRightToolForce()`
10. `GetLeftToolPosition` -> `ArmClient.GetLeftToolPosition()`
11. `GetRightToolPosition` -> `ArmClient.GetRightToolPosition()`
12. `GetLeftJointCurrent` -> `ArmClient.GetLeftJointCurrent()`
13. `GetRightJointCurrent` -> `ArmClient.GetRightJointCurrent()`
14. `GetLeftJointTemperature` -> `ArmClient.GetLeftJointTemperature()`
15. `GetRightJointTemperature` -> `ArmClient.GetRightJointTemperature()`
16. `GetLeftJointPositionMin` -> `ArmClient.GetLeftJointPositionMin()`
17. `GetRightJointPositionMin` -> `ArmClient.GetRightJointPositionMin()`
18. `GetLeftJointPositionMax` -> `ArmClient.GetLeftJointPositionMax()`
19. `GetRightJointPositionMax` -> `ArmClient.GetRightJointPositionMax()`

### 4.2 指令接口
1. `SetWorkMode` -> `ArmClient.SetWorkMode(work_mode)`
2. `SetLeftJointPosition` -> `ArmClient.SetLeftJointPosition(position, velocity_gain, acceleration_gain)`
3. `SetRightJointPosition` -> `ArmClient.SetRightJointPosition(position, velocity_gain, acceleration_gain)`
4. 状态切换（Init/Setup/Stop/Operation/Boot） -> `ArmClient.SetRequestState(request_state)`

## 5. RDK 3.3.5 -> GripperClient 函数映射

### 5.1 状态接口
1. `GetJointNum` -> `GripperClient.GetJointNum()`
2. `GetPosition` -> `GripperClient.GetPosition()`
3. `GetPositionMin` -> `GripperClient.GetPositionMin()`
4. `GetPositionMax` -> `GripperClient.GetPositionMax()`
5. `GetForceData` -> `GripperClient.GetForceData()`
6. `GetRawForceData` -> `GripperClient.GetRawForceData()`
7. `GetTemperature` -> `GripperClient.GetTemperature()`
8. `GetRawTemperature` -> `GripperClient.GetRawTemperature()`

### 5.2 指令接口
1. `SetPosition` -> `GripperClient.SetPosition(position, torque=None)`
2. 状态切换（Init/Setup/Stop/Operation/Boot） -> `GripperClient.SetRequestState(request_state)`
