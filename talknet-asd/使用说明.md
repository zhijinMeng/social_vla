# TalkNet-ASD 摄像头实时演示包（无 ROS）

本压缩包包含：**源码 + 预训练权重 + 一键脚本**，解压即可在 Linux 笔记本上跑「摄像头 + 麦克风」实时说话人检测（Active Speaker Detection）。

## 1. 系统要求

- **系统**：Ubuntu 22.04 / 24.04（或其他带桌面的 Linux）
- **Python**：3.10 或 3.12
- **GPU**：推荐 NVIDIA + CUDA（CPU 也能跑，会慢一些）
- **硬件**：摄像头、麦克风
- **系统库**（麦克风必需）：
  ```bash
  sudo apt update
  sudo apt install -y python3-venv python3-dev libportaudio2 portaudio19-dev
  ```

## 2. 解压

```bash
tar -xzf talknet-asd-camera-release-*.tar.gz
cd talknet-asd-camera-release-*
```

## 3. 安装 Python 环境（首次一次）

```bash
bash scripts/setup_venv.sh
```

若机器**没有 NVIDIA GPU**，编辑 `scripts/setup_venv.sh`，把 PyTorch 安装行改为：

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```

## 4. 运行（无 ROS 摄像头模式）

```bash
bash scripts/run_camera_local.sh
```

- 默认摄像头 `0`，麦克风设备 `4`
- 窗口中按 **`q`** 退出
- 换设备：
  ```bash
  CAMERA_ID=0 MIC_DEVICE=7 bash scripts/run_camera_local.sh
  ```
- 列出麦克风：
  ```bash
  source .venv-talknet/bin/activate
  python -c "import sounddevice as sd; print(sd.query_devices())"
  ```

## 5. 参数说明（常用）

| 参数 | 默认 | 说明 |
|------|------|------|
| `--scoreThres` | -0.2 | 说话判定阈值，越低越敏感 |
| `--windowSec` | 0.5 | ASD 滑窗长度（秒） |
| `--inferStrideSec` | 0.1 | 推理间隔（秒） |
| `--flip` | 开 | 镜像翻转画面 |

终端出现 `[active][camera] ... score=1.xxx` 表示检测到正在说话。

## 6. 包内文件

| 路径 | 说明 |
|------|------|
| `pretrain_TalkSet.model` | TalkNet 预训练权重（~60MB） |
| `model/faceDetector/s3fd/sfd_face.pth` | S3FD 人脸检测权重（~86MB） |
| `online_demoTalkNet.py` | 主程序（文件模式 / 摄像头模式） |
| `scripts/run_camera_local.sh` | 一键启动摄像头演示 |
| `scripts/setup_venv.sh` | 创建虚拟环境 |
| `scripts/setup_weights.sh` | 检查权重是否齐全 |

**未包含**（本包为轻量摄像头版）：`TalkNCE-main/`、`robot_ws/`（ROS2 转头控制，需要时另传完整仓库）。

## 7. 常见问题

**Q: `Invalid sample rate` / 麦克风打不开**  
已内置 44100Hz 采集并重采样到 16kHz。换 `--micDevice` 或 `MIC_DEVICE=7`。

**Q: `QFontDatabase: Cannot find font directory`**  
OpenCV 字体警告，不影响检测，可忽略。

**Q: 说话分数一直接近 0**  
对着麦克风清晰说话；或降低阈值：`bash scripts/run_camera_local.sh --scoreThres -0.3`

**Q: 需要 ROS / 机器人转头**  
使用完整 `talknet-asd` 仓库 + `scripts/run_online_with_ros.sh`（需 ROS2 Humble 与 `robot_ws`）。
